Om qonuni

I = U / R U = I · R R = U / I

U — kuchlanish (V), I — tok (A), R — qarshilik (Ω).

Ketma-ket ulanish

R = R₁ + R₂ + ... + Rₙ

Ketma-ket ulangan rezistorlar qarshiliklari qo‘shiladi.

Parallel ulanish

1/R = 1/R₁ + ... + 1/Rₙ R = R₁R₂ / (R₁ + R₂)

Ikkinchi formula ikkita parallel rezistor uchun.

O‘tkazgich qarshiligi

R = ρ · l / S

ρ — solishtirma qarshilik, l — uzunlik, S — kesim yuzasi. Birliklar mos bo‘lishi shart.

Elektr quvvati

P = U · I P = I² · R P = U² / R

Oxirgi ikkita tenglik rezistiv elementga tegishli.
